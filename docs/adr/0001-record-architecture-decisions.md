# 1. Record architecture decisions

Date: 2026-09-30 · Status: Accepted

## Context

campus-agent is maintained by volunteers in student groups whose members change every
few semesters. Decisions made today must stay understandable for the next maintainers
and for partner groups that want to contribute.

## Decision

Every fundamental decision is recorded as a short Architecture Decision Record in
`docs/adr/`, numbered consecutively, with context, decision and consequences. Decisions
are discussed in public issues or pull requests. A changed decision gets a new ADR that
supersedes the old one.

## Consequences

* New maintainers can follow why the system looks the way it does.
* Pull requests that change a fundamental decision must add or update an ADR (see the
  PR template).
